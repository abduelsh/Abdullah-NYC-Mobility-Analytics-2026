# NYC Mobility Analytics Platform

An end-to-end data engineering and analytics project developed as part of my internship at **Qeema**.

## Project Overview
This project processes New York City High-Volume For-Hire Vehicle (HVFHV) trip data to build an analytical data warehouse and generate meaningful business insights.

## Technologies Used
- Python (Pandas, PyArrow)
- PostgreSQL
- SQL
- Apache Airflow
- Apache Superset

## Project Results
- Processed 20 monthly data files.
- Loaded **411,760,137 records** into PostgreSQL.
- Identified and rejected 16,258 invalid records.
- Built an analytical warehouse with fact and dimension tables.
- Created an interactive dashboard with 8 visualizations.
- Implemented database performance optimizations.
- Used Airflow to validate the database pipeline results.
